# Sistem Panen

## Deskripsi Singkat
Proyek ini merupakan program Python sederhana yang dibuat untuk menghitung total hasil komoditas panen berdasarkan jumlah dan harga, serta dilengkapi dengan fitur kalkulasi diskon.

## Cara Menjalankan Program
1. Pastikan lingkungan Python telah terpasang pada perangkat.
2. Buka terminal atau command prompt, lalu arahkan direktori aktif ke dalam folder proyek ini.
3. Eksekusi program dengan menjalankan perintah: `python panen.py`
